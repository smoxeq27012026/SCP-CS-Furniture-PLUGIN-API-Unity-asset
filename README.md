## / DESCRIPTION / ОПИСАНИЕ

**EN:** 
This asset is a standalone Unity package designed specifically for plugin developers working within the SCP:CLASSIFIED SITE (SCP:CS) ecosystem. It provides a collection of 3D models, textures, and materials extracted directly from the game's environment. 

Primary use case: Placing furniture, lockers, surveillance equipment, and doors within custom SCP rooms or plugin-defined areas in a Unity Editor environment.

**RU:** 
Данный ассет представляет собой автономный пакет для Unity, разработанный специально для создателей плагинов в экосистеме SCP:CLASSIFIED SITE  (SCP:CS). Он содержит коллекцию 3D-моделей, текстур и материалов, извлеченных непосредственно из игрового окружения.

Основное назначение: Размещение мебели, шкафчиков, оборудования слежения и дверей в пользовательских комнатах SCP или зонах, определяемых плагинами, в редакторе Unity.
